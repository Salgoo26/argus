# 자체 점검 결과 (v0.1)

ARGUS v0.1 구현을 마친 뒤 「개인정보의 안전성 확보조치 기준」과 안내서를 기준으로 점검표를 만들고, 실제 동작을 측정해 판정했다. 미충족 항목은 보완한 뒤 같은 방법으로 다시 측정했다.

## 1. 점검 개요

| 항목 | 내용 |
|---|---|
| 기준 | 「개인정보의 안전성 확보조치 기준」(개인정보보호위원회 고시, 2026.7.1 시행), 「개인정보의 안전성 확보조치 기준 안내서」(2025.11), 개인정보 보호법(감시 대상 쇼핑몰 부분) |
| 대상 | A. ARGUS가 고객사(감시 대상 쇼핑몰)의 준수를 돕는가 20개 · B. ARGUS 자체도 개인정보처리시스템으로서 준수하는가 9개 · C. 감시 대상 쇼핑몰 8개, 모두 37개 |
| 방법 | **재현**: 로컬 환경에서 실제 화면·수집 API·DB 툴로 행위를 만들고 접속기록 원본과 DB를 조회해 확인 / **증적**: 코드·설정·테스트로 확인 |
| 일정 | 첫 점검 2026-10-09 → 보완 → 재측정 2026-10-10~11(빈 환경에서 새로 기동) |
| 판정 | ✅ 충족 · 🟡 부분 충족 · ❌ 미충족 · ⚠ 위험 수용 · 📋 다음 버전 |

안내서 쪽수는 인쇄 쪽 기준이다. 점검 범위는 단일 조직 운영을 전제로 정했고, 고시 제17조제2항 "이용기관의 직접 점검"은 해당 없음으로 제외했다.

## 2. 판정 기준: 의무와 참고 기준 구분

판정 중 안내서 원문을 다시 확인해, 128~130쪽(접속기록 누락 사례, 이상행위 판단 기준 예시, "자동화된 방식"의 정의)이 고시 제17조 **공공시스템운영기관** 해설임을 확인했다. 민간 쇼핑몰에는 법적 의무가 아니므로, 이 쪽을 근거로 한 항목은 "공공 기준 참고"로 분류해 판정했다.

| 조항 | 적용 대상 | 해당 항목 |
|---|---|---|
| 고시 제8조 (안내서 91~95, FAQ 147) | 모든 개인정보처리자 | A1·A2·A6·A7·A8·A9·A10·A12·A16·A17·A18 |
| 고시 제17조 (안내서 128~130) | 공공시스템운영기관 — **참고** | A3·A4·A5·A11·A13·A14·A15 |
| 고시 제4조제4항·제5조제3항 | 모든 개인정보처리자 | A19·A21 |
