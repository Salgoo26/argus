# 개인정보 영향평가(PIA) 진행 현황

> 커머스 플랫폼(쇼핑몰·백오피스)을 대상으로 개인정보보호위원회「개인정보 영향평가 수행안내서」(2025.10)의 수행 단계를 따라 진행 중인 자체 영향평가입니다.
> 최종 갱신: 2026-10-23

## 1. 평가 개요

| 항목 | 내용 |
|---|---|
| 평가 대상 | 쇼핑몰(고객 화면), 백오피스(관리자 화면), platform-api, platform-db, DB 게이트웨이 |
| 연계 시스템 (평가 제외) | ARGUS, 가상 PG(결제 위탁), 가상 택배(배송 위탁), 가상 본인확인 창. 흐름도·구조도에 표시하고, 넘겨주는 항목과 위탁 관리만 평가 |
| 평가 기준 | 수행안내서(2025.10) 5개 영역·28개 분야·121개 지표. 3영역(처리단계별 보호조치)·4영역(기술적 보호조치) 중심, 판단할 수 없는 항목은 "해당 없음 + 사유"로 기재 |
| 수행 방식 | 외부 평가기관 입장에서 평가자료(설계 문서·처리방침·화면)를 분석하고, 코드·DB 확인이 필요한 부분은 시스템 담당자 인터뷰·실사로 확인 |
| 한계 | 시스템 개발자와 평가자가 같아 독립성이 없으며, 지정 영향평가기관의 정식 평가가 아닌 안내서 방법론에 따른 자체 평가 |

## 2. 진행 단계

| 단계 | 상태 | 산출물 |
|---|---|---|
| ① 영향평가 수행계획 수립 | 완료 | 수행계획서 |
| ② 평가자료 수집 | 완료 | 법률·규정 목록, 평가자료 목록, 사업개요서 |
| ③ 개인정보 흐름분석 | **진행 중** | 3.1 개인정보 처리업무 현황 분석 완료(영향도 등급표·처리 업무표), 업무흐름도 작성 중. 이후 흐름표·흐름도·정보시스템 구조도 |
| ④ 개인정보 침해요인 분석 | 예정 | 평가항목 점검표, 침해요인 목록, 위험도 산정 |
| ⑤ 개선계획 수립 | 예정 | 개선계획 |
| ⑥ 영향평가서 작성 | 예정 | 영향평가서 |

## 3. 현재까지 결과: 개인정보 처리 업무표

안내서 영향도 등급표 예시(1등급 5점·2등급 3점·3등급 1점)를 적용했고, 업무의 영향도는 업무 안 항목 중 가장 높은 자산가치입니다. 건수는 향후 1년 예상 정보주체 10만 명 기준의 추정치(중복 제거)입니다. 시스템 데이터는 모두 테스트 데이터입니다.

| # | 평가업무명 | 주요 처리 개인정보 | 주관부서 | 건수 | 영향도 |
|---|---|---|---|---|---|
| 1 | 회원관리 | 성명, 아이디, 이메일, 전화번호, 비밀번호, CI·DI, 생년월일, 배송지 주소 등 | 커머스운영팀 | 10만 | 5 |
| 2 | 주문·결제 | 구매자·수신자 성명·연락처, 배송지 주소, 마스킹 카드번호, 입금자명 등 | 커머스운영팀 | 6만 | 3 |
| 3 | 배송 | 수신자 성명·연락처, 배송지 주소, 배송 메모, 송장번호 등 | 커머스운영팀 | 6.5만 | 3 |
| 4 | 취소·반품·환불 | 환불계좌(은행, 예금주, 계좌번호), 주문번호, 송장번호 | 커머스운영팀 | 6천 | 5 |
| 5 | 고객 상담 | 성명, 회원번호, 상담내용 | 커머스운영팀 | 5천 | 3 |
| 6 | 마케팅 | 성명, 이메일, 전화번호, 주문 상품 | 마케팅팀 | 4만 | 3 |
| 7 | 계정·권한 관리 | 사번, 성명, 부서, 역할, 재직 상태, 비밀번호 | IT팀 | 10 | 5 |
| 8 | 접속기록 관리 | 사번, 접속 일시, 접속지(IP), 수행업무, 처리한 회원번호 | IT팀 | 10만 | 1 |

DB 직접접근은 별도 업무가 아니라 여러 업무에서 쓰는 접근 경로로 보고, 흐름표·흐름도의 이용 단계에 표시합니다.

## 4. 다음 단계

③ 흐름분석(업무흐름도·흐름표·흐름도·구조도)을 마친 뒤 ④ 평가항목 점검과 침해요인 분석으로 넘어갑니다. 침해요인과 개선사항은 ④·⑤ 단계 결과로 이 문서에 추가합니다.
