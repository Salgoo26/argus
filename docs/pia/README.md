# 개인정보 영향평가(PIA)

> 커머스 플랫폼(쇼핑몰·백오피스)을 대상으로 개인정보보호위원회「개인정보 영향평가 수행안내서」(2025.10)의 수행 단계를 따라 진행 중인 자체 영향평가입니다.
> 최종 갱신: 2026-10-27

## 평가 개요

| 항목 | 내용 |
|---|---|
| 평가 대상 | 쇼핑몰(고객 화면), 백오피스(관리자 화면), platform-api, platform-db, DB 게이트웨이 |
| 연계 시스템 (평가 제외) | ARGUS, 가상 PG(결제 위탁), 가상 택배(배송 위탁), 가상 본인확인 창. 흐름도·구조도에 표시하고, 넘겨주는 항목과 위탁 관리만 평가 |
| 평가 기준 | 수행안내서(2025.10) 5개 영역·28개 분야·121개 지표. 3영역(처리단계별 보호조치)·4영역(기술적 보호조치) 중심, 판단할 수 없는 항목은 "해당 없음 + 사유"로 기재 |
| 평가 시기 | 구축을 마치고 운영 중인 시스템을 대상으로, 전반적인 개인정보 보호체계를 점검·개선하기 위해 수행하는 평가입니다(수행안내서 4.2 "기 구축되어 운영 중인 시스템의 경우"). 신규 구축 시 설계 완료 전에 수행하는 사전 평가(4.1)가 아니므로, 개선계획은 설계 반영이 아닌 운영 중 보완으로 이행합니다 |
| 수행 방식 | 외부 평가기관 입장에서 평가자료(설계 문서·처리방침·화면)를 분석하고, 코드·DB 확인이 필요한 부분은 시스템 담당자 인터뷰·실사로 확인 |
| 한계 | 시스템 개발자와 평가자가 같아 독립성이 없으며, 지정 영향평가기관의 정식 평가가 아닌 안내서 방법론에 따른 자체 평가 |

## 1. 영향평가 수행계획 수립

### 1.1 영향평가 수행계획 수립

평가 목적, 대상과 범위, 평가 주체, 기간, 절차, 평가기준과 평가항목, 자료수집·분석 계획, 결과 정리, 품질관리 방안을 정했습니다. 1인 자체 평가이므로 사전준비 단계(필요성 검토·대가 산정·평가기관 선정)는 생략했습니다.

- 산출물: [영향평가 수행계획서](영향평가_수행계획서.md)

### 1.2 ~ 1.4 영향평가팀 구성·역할 정의·운영계획 수립

1인 자체 평가이므로 평가 수행자 1명과 시스템 담당자(인터뷰·실사 대응) 역할만 둡니다. 내용은 수행계획서 3절(평가 주체)에 있습니다.

## 2. 평가자료 수집

### 2.1 내부 정책자료 분석

개인정보 처리방침, 이용약관·동의 문안, 정책정의서(권한·마스킹·보관·파기)를 모으고, 없는 자료(내부 관리계획 등)는 대체 자료와 사유를 적었습니다.

### 2.2 외부 정책자료 분석

안내서의 주요 법규를 기준으로 적용·참고·적용 제외 법령을 나누고, 적용 제외는 사유를 적었습니다(예: 신용정보법, 위치정보법).

### 2.3 대상시스템 관련 자료 분석

요구사항 정의서, 아키텍처 설계서, API 명세서, DB 스키마, 화면 등을 모으고, 사업 개요·시스템 구성·정보주체·처리 업무와 법적 근거·외부 연계를 사업개요서로 정리했습니다.

- 산출물: [법률·규정 목록 및 평가자료 목록](평가자료_목록.md), [사업개요서](사업개요서.md)

## 3. 개인정보 흐름분석

### 3.1 개인정보 처리업무 현황 분석

#### 3.1.1 개인정보 영향도 등급표 작성

안내서 등급표 예시(1등급 5점·2등급 3점·3등급 1점)를 그대로 쓰고, 시스템이 처리하는 개인정보 항목을 등급별로 대응시켰습니다. 여러 등급에 걸치는 항목은 상위 등급으로 봤습니다.

- 산출물: [개인정보 영향도 등급표](개인정보_영향도_등급표.md) (원본 [xlsx](개인정보_처리업무_현황분석.xlsx))

#### 3.1.2 개인정보 처리업무표 작성

개인정보를 처리하는 업무 8개를 도출하고, 업무별 처리 목적·처리 개인정보·주관부서·건수·영향도를 정리했습니다. 영향도는 업무에서 처리하는 항목 중 가장 높은 자산가치이고, 건수는 향후 1년 예상 정보주체 10만 명 기준 추정치(중복 제거)입니다. DB 직접접근은 별도 업무가 아닌 접근 경로로 보고 흐름표·흐름도에 표시합니다.

- 산출물: [개인정보 처리업무표](개인정보_처리업무표.md) (원본 [xlsx](개인정보_처리업무_현황분석.xlsx))

#### 3.1.3 개인정보 처리업무 흐름도 작성

처리업무표의 업무 8개마다 한 장씩, 업무를 수행하는 고객·시스템·부서·연계기관을 레인으로 나눠 그렸습니다. 연계기관(본인확인 서비스·PG·택배사)과 ARGUS는 표시만 하고 내부 처리는 평가하지 않습니다.

- 산출물: [개인정보 처리업무 흐름도](개인정보_처리업무_흐름도.md)
