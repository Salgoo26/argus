# 현황파악 — 4.7 개인정보의 파기

> 안내서 현황파악(4.2, 61~64쪽)의 평가항목별 결과 양식으로 작성했습니다. 평가자료(처리방침·설계 문서)와 흐름분석 산출물, 시스템 담당자 인터뷰·실사로 판정했습니다
> 확인: 이행 / 부분이행 / 미이행. 파기 시점·절차(보유기간 경과 후 파기)는 3.5.1에서 판정하고, 여기서는 파기 방법만 봅니다

## 4.7.1

| 구분 | 내용 |
|---|---|
| 질의문 코드 | 4.7.1 |
| 질의문 | 개인정보를 파기할 경우 복구 또는 재생되지 않는 방법으로 파기하도록 계획하고 있습니까? |
| 확인 | 이행 |
| 평가 근거 및 의견 | - 회원 탈퇴 시 회원정보를 DB에서 삭제하고, 분리보관으로 옮긴 문의 내용은 운영 테이블에서 덮어써 지움<br>- 백업 파일은 암호화해 보관하고 7일 뒤 자동 삭제함 |
| 항목 설명 | ○ 개인정보를 복구·재생되지 않도록 완전파괴·덮어쓰기 등으로 파기하고, 일부만 파기할 때는 삭제 후 복구되지 않도록 관리함 |
| 평가 예시 | ○ 이행: 저장 매체와 파기 범위에 맞는 방법으로 복구되지 않게 파기하는 경우<br>○ 부분이행: 일부 개인정보를 복구 가능한 상태로 남기는 경우 |
| 관련 법령 및 문서 | 개인정보 보호법 제21조, 개인정보 보호법 시행령 제16조, 개인정보의 안전성 확보조치 기준 제13조 |
