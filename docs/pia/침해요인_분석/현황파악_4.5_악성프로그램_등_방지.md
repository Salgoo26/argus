# 현황파악 — 4.5 악성프로그램 등 방지

> 안내서 현황파악(4.2, 61~64쪽)의 평가항목별 결과 양식으로 작성했습니다. 평가자료(처리방침·설계 문서)와 흐름분석 산출물, 시스템 담당자 인터뷰·실사로 판정했습니다
> 확인: 이행 / 부분이행 / 미이행

## 4.5.1

| 구분 | 내용 |
|---|---|
| 질의문 코드 | 4.5.1 |
| 질의문 | 악성프로그램 등을 점검, 치료할 수 있는 보안 프로그램을 설치하고 최신업데이트 및 악성프로그램의 주기적 점검 등 대응조치를 실시하도록 계획하고 있습니까? |
| 확인 | 부분이행 |
| 평가 근거 및 의견 | - 취급자 PC에는 실시간 감시와 자동 업데이트가 켜진 백신을 사용함<br>- 서버에는 악성프로그램을 방지·치료하는 보안 프로그램을 설치하는 계획이 없음 |
| 항목 설명 | ○ 개인정보처리시스템과 취급자 PC에 백신 등 보안 프로그램을 설치해 실시간 감시·자동 업데이트(일 1회 이상)로 최신 상태를 유지하고, 발견된 악성프로그램을 삭제하는 등 대응함 |
| 평가 예시 | ○ 이행: 대상 서버·PC에 보안 프로그램을 설치하고 최신 상태로 운영하는 경우<br>○ 부분이행: 일부 대상에만 설치하거나 업데이트·점검이 이루어지지 않는 경우 |
| 관련 법령 및 문서 | 개인정보 보호법 제29조, 개인정보의 안전성 확보조치 기준 제9조제1항 |

## 4.5.2

| 구분 | 내용 |
|---|---|
| 질의문 코드 | 4.5.2 |
| 질의문 | 악성프로그램 관련 경보가 발령된 경우 또는 사용 중인 응용프로그램, 운영체제 소프트웨어 제작업체에서 보안 업데이트 공지가 있는 경우, 이에 따른 업데이트가 지체없이 실시되도록 계획하고 있습니까? |
| 확인 | 부분이행 |
| 평가 근거 및 의견 | - 응용프로그램이 사용하는 라이브러리와 컨테이너 이미지는 자동 알림(Dependabot)으로 보안 업데이트를 확인함<br>- 서버 운영체제의 보안 업데이트 적용 절차와 적용 전 영향도 분석 절차가 없음 |
| 항목 설명 | ○ 운영체제·응용프로그램의 보안 업데이트 공지나 악성프로그램 경보가 있으면 영향도를 분석한 뒤 지체 없이 적용하고, 기술 지원이 끝난 운영체제는 업그레이드함 |
| 평가 예시 | ○ 이행: 운영체제와 응용프로그램 모두 보안 업데이트를 지체 없이 적용하는 절차가 있는 경우<br>○ 부분이행: 일부 소프트웨어에만 보안 업데이트 절차가 있는 경우 |
| 관련 법령 및 문서 | 개인정보 보호법 제29조, 개인정보의 안전성 확보조치 기준 제9조제2항 |
