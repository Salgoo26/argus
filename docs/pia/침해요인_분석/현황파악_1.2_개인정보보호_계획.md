## 1.2.1

| 구분 | 내용 |
|---|---|
| 질의문 코드 | 1.2.1 |
| 질의문 | 개인정보가 분실‧도난‧유출‧위조‧변조 또는 훼손되지 아니하도록 내부 의사결정 절차를 통하여 필수 사항을 포함하는 내부 관리계획을 수립·시행하고 있습니까? |
| 확인 | 미이행 |
| 평가 근거 및 의견 | - 설계 문서에 접근 권한·암호화·접속기록 등 안전조치 기준은 있으나, 내부 의사결정 절차를 거쳐 수립·시행한 내부 관리계획이 없음 |
| 항목 설명 | ○ 안전성 확보조치 기준의 필수 사항을 담은 내부 관리계획을 공식 절차로 수립·시행하고, 변경 시 수정 이력을 관리함 |
| 평가 예시 | ○ 이행: 필수 사항을 모두 담은 내부 관리계획을 승인받아 시행하고 공유한 경우<br>○ 부분이행: 내부 관리계획은 있으나 필수 사항 일부가 빠지거나 승인·공유 절차가 없는 경우 |
| 관련 법령 및 문서 | 개인정보 보호법 제29조, 개인정보의 안전성 확보조치 기준 제4조제1항 |
