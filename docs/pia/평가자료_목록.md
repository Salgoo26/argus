### 1-3. 적용 제외 (사유)

| 법규 | 사유 |
|---|---|
| 신용정보의 이용 및 보호에 관한 법률·시행령·신용정보업감독규정 | "신용정보제공·이용자"(법 제2조제7호)는 상거래를 위해 신용정보를 타인에게 제공하거나 타인에게서 받아 영업에 이용하는 자이고, 시행령 제2조제6항의 "준하는 자"는 금융·준금융기관입니다. 쇼핑몰은 PG에서 승인 결과만 받고 신용 판단·할부·외상이 없습니다 |
| 위치정보의 보호 및 이용 등에 관한 법률 | 위치정보를 처리하지 않습니다 |
| 개인정보 처리 방법에 관한 고시 | 공공기관의 목적 외 이용 공고·서식과 서면 동의 표시 방법이 대상입니다. 공공기관이 아니고 동의는 온라인으로만 받습니다 |
| 개인정보 위험도 분석 기준 | 고유식별정보 암호화에 상응하는 조치를 판단하는 기준입니다. 고유식별정보를 받지 않습니다 |
| 가명정보의 결합 및 반출 등에 관한 고시 | 가명정보를 처리하지 않습니다 |
| 개인정보 국외 이전 운영 등에 관한 규정 | 국외 이전이 없습니다(처리방침 7절) |
| 전자금융거래법 | 잠정. 카드 결제는 PG(수탁자) 결제창에서 끝나고 쇼핑몰은 PG가 돌려준 마스킹 카드번호·승인번호만 받습니다. 무통장입금은 관리자가 입금을 직접 확인합니다. 쇼핑몰은 전자금융업자가 아닙니다. ④에서 결제 흐름을 보고 확정합니다 |
| 위치정보 보호조치 기준, 생체정보 보호 가이드라인, 가명정보 처리 가이드라인 | 위치·생체·가명정보를 처리하지 않습니다 |
